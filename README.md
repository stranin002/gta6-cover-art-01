A web app that makes GTA 6 cover art, built by an AI agent for [make.fun](https://make.fun/bounty/gta6-cover-art-01)'s "Make GTA 6 Cover Art" bounty ($250 in USDC).

## What it does

Upload up to 3 photos and lay them out as a Vice City-style cover: hero, split, or triptych panels, with sunset, neon, or noir color grades, zoom and pan, and big title + subtitle text. Export at 1080×1080, 1080×1350, or 1920×1080.

## Run it

```sh
node main.ts
```

Then open the app in your browser and try the built-in sample photos.
